# -AI-Powered-Audio-Recommendation-Engine-Dynamic-Web-Host
🎧 SmartStream AI: Dynamic Media Web Server &amp; ML Recommendation Engine
📌 Project Overview
SmartStream AI is an end-to-end machine learning web application that transforms a raw text-based dataset of 1,000 songs into a fully interactive, playable media dashboard. Built entirely in Python, this project features a custom content-based recommendation engine and a dynamic web-scraping backend that bypasses the need for local storage by pulling real-time audio streams directly from YouTube.

This project was developed by Deepanshu as part of an advanced AI/ML engineering portfolio, demonstrating full-stack data science capabilities from data ingestion to frontend deployment.

✨ Core Features & Technical Architecture (From Beginning to End)
1. Data Ingestion & Preprocessing
Automated Data Loading: The system ingests a raw .xlsx dataset (Lata_Mangeshkar_1000_Songs_Dataset.xlsx) containing metadata such as Song Title, Movie Name, Release Year, and Singer.
Data Cleansing: Utilizes pandas to sanitize the data, stripping whitespace, handling missing values, and formatting strings to ensure perfectly clean inputs for the machine learning model.
2. The Machine Learning Engine (Content-Based Filtering)
Feature Engineering: Combines categorical and numerical metadata (Movie Name and Release Year) into a unified text feature profile for each track.
TF-IDF Vectorization: Deploys Scikit-Learn's TfidfVectorizer to convert the text profiles into a matrix of TF-IDF features, mathematically weighing the importance of specific contextual words.
Cosine Similarity Matrix: Calculates the cosine similarity across the vectorized matrix to determine the exact mathematical distance between songs, allowing the AI to recommend the top 4 most contextually relevant tracks instantly.
3. Dynamic Media Retrieval (Real-Time Web Scraping)
Bypassing Local Storage Constraints: Because the original dataset contains only text, the backend is engineered to synthesize highly specific search queries (e.g., "Song Title + Movie + Singer + full song original").
URL Encoding & Parsing: Uses urllib to encode the query and securely scrape YouTube's HTML source code in real-time.
Regex Extraction: Implements Regular Expressions (re) to locate the exact 11-character YouTube Video ID from the scraped HTML and dynamically constructs an embedded iframe.
4. Modern User Interface & Local Server Deployment
Gradio Web Host: Spins up a localized web server using gradio, providing a seamless and interactive user experience.
Dynamic HTML/CSS Styling: Features a custom-built, aesthetically pleasing dashboard using creative CSS gradients, drop shadows, and formatted typography to display track metadata.
Error Handling & Fallbacks: Includes built-in safety checks that prevent the server from crashing if a user submits an empty query or if the dataset fails to load.
🛠️ Tech Stack
Language: Python
Data Manipulation: Pandas
Machine Learning: Scikit-Learn (TfidfVectorizer, cosine_similarity)
Web Scraping: urllib, re (Regular Expressions)
Frontend/Server: Gradio, HTML5, CSS3
🚀 How It Works (Step-by-Step Flow)
Bootup: The server initializes, loads the dataset, and pre-trains the TF-IDF recommendation model in the background.
User Selection: The user selects a track from the interactive dropdown menu.
Backend Processing:
The ML model cross-references the Cosine Similarity matrix and fetches 4 tailored recommendations.
The scraping engine silently queries YouTube, extracts the relevant media ID, and prepares the iframe.
UI Update: The Gradio dashboard refreshes instantly, displaying the real-time playable YouTube video, the beautifully formatted metadata, and the AI-generated track recommendations.
